# Changelog

## [0.1.0] — 2026-07-25

### Added

- Initial release
- iPhone-first PWA remote control surface for Pi coding agent
- Pairing-based authentication with rate-limited one-time codes
- Session management with HttpOnly/SameSite/Strict cookies and CSRF protection
- Instance lifecycle management (spawn, stop, list, events)
- SSE streaming with keepalive, Last-Event-ID history replay, and backpressure
- Model discovery, selection, and thinking-level controls
- Command whitelist with per-field validation (~40 RPC command types)
- Image attachment support (JPEG/PNG/WebP/GIF) with size and count limits
- Controller lease system (single controller per instance)
- Static file serving with path-traversal protection
- Comprehensive security headers (CSP, HSTS, COOP, CORP, X-Frame-Options)
- Service worker with app-shell caching
- Accessibility-first PWA (ARIA landmarks, screen reader, keyboard, reduced motion)
- Dark/light theme support with CSS custom properties
- Node.js native test runner test suite
- Biome linter and formatter configuration
